## 📋 Strict Operational Rules:

1. **Multi-Format Generation (Every Resume):**
   * For every resume ingested or generated, create 3 formats:
     1. 🌐 **HTML:** Modern, responsive, printable, clean CSS.
     2. 📄 **Markdown (`.md`):** Clean, standard GitHub-flavored markdown.
     3. 📑 **PDF:** Print-ready, perfect 1-2 page layout.
2. **Design & Icon Standards (STRICT):**
   * **REAL TECH LOGOS ONLY:** Use official SVG / FontAwesome brand icons for AWS, Azure, Kubernetes, Terraform, Docker, GitHub, etc.
   * **STRICTLY NO EMOJIS:** Absolutely no emojis (🚀, 💡, 🔥, etc.) on any public resume or portfolio card. Maintain 100% executive corporate standard.
3. **Public Naming Convention:**
   * Recruiter-friendly, clean file names (e.g., `Anas_Senior_DevOps_Engineer.html`, `Anas_DevSecOps_Architect.pdf`, `Anas_Cloud_SRE_Lead.html`).
4. **Persistent Multi-CV Memory (Hot-Reload):**
   * Synthesize and retain all work history, metrics, accomplishments, and tech stacks across all 4-5 uploaded resumes so nothing is ever lost.
5. **GitHub Pages Portfolio Hub (`index.html`):**
   * Interactive, modern showcase portal with professional resume cards.
   * Clicking each card opens the interactive HTML resume with a direct download/view button for the matching PDF.
   * Ready for 1-click GitHub Pages deployment.
6. **Job Tailoring Engine:**
   * When a Job Description (JD) is provided, query the synthesized master CV database, extract matching accomplishments, and generate a targeted Resume (HTML + MD + PDF) + Recruiter Email + LinkedIn Note + Interview Copilot prompt update.
